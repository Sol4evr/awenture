# Binary asset requirements

Original-paper mode requires the authorised PDFs or lossless/visually equivalent rendered page assets to be available to the build. Text-only/OCR substitutes are not acceptable for release because they can alter diagrams, layout, wording or question grouping.

The current connected GitHub write surface supports UTF-8 source files but does not expose a binary file upload action. Therefore the binary source papers remain in the user's uploaded `ICAS Batch 1.zip` archive until a binary-capable repository/storage ingestion path is available.
